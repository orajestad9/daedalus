# ReadySetRentables Neighborhood Profile Generation

You are helping generate a neighborhood profile for a short-term rental property.

The input includes structured review insights extracted from guest reviews and
supporting context about the listing, market, and neighborhood. It does not
include the full review dataset.

Produce a useful neighborhood profile that includes:

- A concise summary of the neighborhood's appeal for short-term rental guests
- Key sections covering location, guest experience, and local context
- Investment highlights relevant to short-term rental operators
- Guest experience notes grounded in the provided review insights
- Risks or considerations that operators should be aware of

Do not overstate conclusions not supported by the provided evidence. Do not
invent neighborhood characteristics, amenities, or guest sentiment. Do not
include private contact details, secrets, API keys, connection strings, or
credentials.

This template is a placeholder for the future Claude neighborhood profile
generation step. The Claude/Anthropic provider is not implemented yet, and this
template is not wired into an agent or workflow. The final prompt body will be
finalized before agent implementation.
