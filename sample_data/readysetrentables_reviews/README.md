# ReadySetRentables Review Sample Data

This directory contains fully synthetic Airbnb-style review data for exercising
the ReadySetRentables review-processing workflow during local development and
tests.

Do not commit real, private, or customer-provided Airbnb exports to this
repository. Keep private datasets in local-only paths such as `data/private/`,
`data/local/`, or an ignored `private/` or `local/` folder under `sample_data/`.
